Python Basics
A collection of beginner-friendly Python programs created for practice and learning core programming concepts.
GitHub Username: @bhakharhimanshu
Repository: python-basics-25bcon1800
📌 About the Project
This repository contains Python programs that demonstrate commonly used programming concepts, including dictionaries, factorial calculation, Fibonacci sequences, list operations, and multiplication tables.
The programs are designed to be easy to run, understand, and modify while building a strong foundation in Python.
📂 Project Structure
python-basics-25bcon1800/
├── dictionary.py       # Student Management System using a dictionary
├── factorial.py        # Factorial calculator with input validation
├── fibonacci.py        # Fibonacci sequence generator
├── list_program.py     # Interactive list manager
├── multiplication.py   # Custom multiplication table generator
└── README.md
Note: list_program.py is recommended instead of list.py to avoid conflicts with Python's built-in list type and imports.

✨ Features
- Student Management System: Add, search, update, and display student records during the current run.
- Factorial Calculator: Calculate factorials for non-negative integers and show the number of digits in the result.
- Fibonacci Generator: Generate a requested number of Fibonacci terms using an iterative approach.
- List Manager: Add, remove, search, sort, and display list items through a menu.
- Multiplication Table Generator: Generate tables over a custom range in ascending or descending order.
- Input Validation: Handle common invalid inputs and out-of-range values.
🛠️ Requirements
- Python 3.8 or newer recommended
- No third-party packages required
🚀 Getting Started
1. Clone the repository
git clone https://github.com/bhakharhimanshu/python-basics-25bcon1800.git
2. Open the project folder
cd python-basics-25bcon1800
3. Run a program
python dictionary.py
You can run any other program in the same way:
python factorial.py
python fibonacci.py
python list_program.py
python multiplication.py
On some systems, use python3 instead of python.
💻 Example
Run the Fibonacci generator:
Enter number of terms (0-10000): 7
Fibonacci Sequence:
0, 1, 1, 2, 3, 5, 8
Run the multiplication table generator:
Enter number: 5
Starting multiplier: 1
Ending multiplier: 10
Reverse order? (yes/no): no

Multiplication Table of 5
5 x 1 = 5
5 x 2 = 10
...
5 x 10 = 50
